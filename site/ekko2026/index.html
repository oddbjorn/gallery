One step first

Open this gallery through a local server.

You opened index.html directly from disk. Browsers block ES modules and JSON reads on file:// pages, so the gallery cannot start that way. 

cd /path/to/gallery
npm start

Start the server from this folder, then open the URL it prints — normally http://127.0.0.1:4173.

The server is already installed. No build step is needed to view the current collection.
